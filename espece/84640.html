Le Poliste gaulois ( Polistes dominula ) femelle a les joues jaunes, ses antennes sont noires sur le dessus jusqu’à la moitié du 3ème article puis entièrement jaune orangé, le dernier sternite est jaune, les mandibules noires, le clypéus jaune pouvant être barré de noir. Le mâle a la face jaune, les côtés du clypéus parallèles, les mandibules robustes, les tempes convexes derrière les yeux et les antennes noires dessus jusqu’au 3ème article.
